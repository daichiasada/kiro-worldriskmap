# 要件定義 (Requirements) — 地政学リスク可視化サイト

## はじめに
国家間および各国の地政学リスクを、公開されている定量化指標に基づく合成スコアとして
可視化する Web アプリケーションを構築する。利用者は世界地図・ランキング・国別詳細・
2国間比較を通じてリスクを直感的に把握できる。

要件は EARS 記法 (Easy Approach to Requirements Syntax) で記述する。

## 要件

### 要件1: 合成リスクスコアの算出
**ユーザーストーリー:** アナリストとして、各国の地政学リスクを単一の比較可能な数値で
把握したい。

#### 受け入れ基準
1. WHEN ある国の5つのリスクコンポーネント(conflict/governance/economic/external/social)が与えられる THE SYSTEM SHALL それらの重み付き平均として 0〜100 の合成スコアを算出する
2. THE SYSTEM SHALL 合成スコアを常に 0 以上 100 以下に収める
3. WHEN すべてのコンポーネント値が等しい THE SYSTEM SHALL 合成スコアをその値に一致させる
4. IF いずれかのコンポーネントが 0〜100 の範囲外である THEN THE SYSTEM SHALL 範囲内にクランプして算出する
5. THE SYSTEM SHALL 合成スコアからリスクバンド(低/中/高/深刻)を一意に分類する

### 要件2: 世界地図による可視化
**ユーザーストーリー:** 利用者として、世界全体のリスク分布を一目で把握したい。

#### 受け入れ基準
1. WHEN サイトを開く THE SYSTEM SHALL 各国を合成スコアに応じて色分けしたコロプレス世界地図を表示する
2. WHEN 国にカーソルを合わせる THE SYSTEM SHALL その国名と合成スコア・リスクバンドをツールチップ表示する
3. WHEN 国をクリックする THE SYSTEM SHALL その国の詳細ビューを開く
4. THE SYSTEM SHALL 色とスコアの対応を示す凡例を表示する

### 要件3: ランキング表示
**ユーザーストーリー:** 利用者として、リスクの高い/低い国を順位で確認したい。

#### 受け入れ基準
1. THE SYSTEM SHALL 全対象国を合成スコアの降順で並べたランキングを表示する
2. WHEN 利用者が昇順/降順を切り替える THE SYSTEM SHALL 並び順を即座に更新する
3. WHEN 利用者が検索語を入力する THE SYSTEM SHALL 国名で絞り込んだ結果を表示する

### 要件4: 国別詳細ビュー
**ユーザーストーリー:** 利用者として、特定国のリスク内訳を理解したい。

#### 受け入れ基準
1. WHEN 国の詳細を開く THE SYSTEM SHALL 5つのコンポーネントの内訳を可視化(バー等)で表示する
2. THE SYSTEM SHALL 合成スコア・リスクバンド・各指標の出典注記を表示する

### 要件5: 2国間比較
**ユーザーストーリー:** 利用者として、2つの国の地政学的緊張度を比較したい。

#### 受け入れ基準
1. WHEN 利用者が2国を選択する THE SYSTEM SHALL 両国の合成スコアと2国間リスクスコアを並べて表示する
2. THE SYSTEM SHALL 2国間リスクスコアを対称(国の順序に依存しない)に算出する

### 要件6: 出典と透明性
**ユーザーストーリー:** 利用者として、数値の根拠を確認したい。

#### 受け入れ基準
1. THE SYSTEM SHALL 使用した指標名・出典・年次・算出方法をサイト内に明記する
2. THE SYSTEM SHALL スコアが教育・可視化目的の合成値である旨の注意書きを表示する

### 要件7: 品質と非機能
#### 受け入れ基準
1. THE SYSTEM SHALL TypeScript strict でビルドが通る
2. THE SYSTEM SHALL ドメインロジックに対する単体テストと Property-Based Test を備える
3. THE SYSTEM SHALL レスポンシブで、主要ブラウザで表示できる
4. THE SYSTEM SHALL 静的サイトとしてビルド・デプロイできる

### 要件8: 代表国から見た二国間関係性ビュー (Issue #7)
**ユーザーストーリー:** アナリストとして、G7 等の代表国を起点に、その国から見た各国との
関係性(同盟/中立/対立)と二国間リスクを把握したい。

#### 受け入れ基準
1. WHEN 利用者が起点となる代表国を選択する THE SYSTEM SHALL その国から見た各国との関係区分・二国間リスクスコア・相手国の合成スコアの一覧を表示する
2. THE SYSTEM SHALL 関係区分(同盟/中立/対立)を色で区別して表示する
3. WHEN 関係データに明示的な定義が無い相手国 THE SYSTEM SHALL 既定として中立(neutral)を用いる
4. THE SYSTEM SHALL 起点国自身を一覧から除外する
5. THE SYSTEM SHALL 一覧を関係区分(対立→中立→同盟)、同区分内は二国間リスク降順で並べる
